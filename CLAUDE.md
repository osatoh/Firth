# CLAUDE.md

## Language

- Write everything in this repository in English: code, comments, documentation, commit messages, branch names, and pull request titles and descriptions.
- This applies even when the conversation with the user is in another language.
- The one exception is user-facing copy: the product is aimed at Japanese users, so the text
  end users read (view copy, flash messages, and the spec expectations that assert on them) is
  written in Japanese. Such copy belongs in a locale file under `config/locales`, not inline in
  views and controllers.

## Pull requests

- Do not assign Copilot as a reviewer on pull requests, and do not request a Copilot review.
